
🚀 Aghil Terminal Helper

دستیار تعاملی ترمینال برای Linux و Termux 🐧

به جای اینکه هر بار دنبال دستور بگردی، Aghil Terminal Helper منوی مناسب را نشان می‌دهد و در بسیاری از عملیات، مرحله بعدی را هم پیشنهاد می‌کند.

✨ امکانات

- 📁 مدیریت فایل و پوشه
- 📦 Package Manager
- 🐙 Git / GitHub
- 🐍 Python
- ⚙️ اطلاعات سیستم
- 🔧 اجرای Script
- 🔎 جستجوی دستور
- ❓ نمایش Help
- 💡 پیشنهاد مرحله بعد
- 🎨 رابط رنگی
- 📱 مناسب Termux
- 🖥️ مناسب Linux

نصب

git clone https://github.com/Aghil-Echresh/aghil-terminal-helper.git
cd aghil-terminal-helper
bash install.sh

بعد اجرا کن:

aghil

حذف

bash uninstall.sh
